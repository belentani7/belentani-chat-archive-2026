# Belentani — Archivo completo del proyecto

Este paquete contiene el código fuente exportado, documentación, investigación, assets generados, fuentes aportadas por el usuario, versiones conocidas y archivo recuperable del chat. El juego se ejecuta como aplicación web; consulte `project/README.md` y los documentos de diseño para continuar.

El paquete se preparó para un repositorio privado y una carpeta privada de Google Drive. No contiene `node_modules`, secretos, tokens, credenciales ni logs de plataforma.
